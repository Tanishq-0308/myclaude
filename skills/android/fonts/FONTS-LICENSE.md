# Fonts

Single-stroke SVG fonts from the `hersheytext` package (https://github.com/techninja/hersheytext, MIT),
converted by Windell H. Oskay / Evil Mad Scientist Laboratories.

- HersheySans1.svg, HersheyScript1.svg: Hershey fonts (Dr. A. V. Hershey, U.S. National Bureau of Standards), public domain / liberal license.
- EMSReadability.svg, EMSAllure.svg: Sheldon B. Michaels, SIL Open Font License 1.1 (https://openfontlicense.org).
  EMS Allure is a derivative of Allura by Rob Leuschke (TypeSETit).
